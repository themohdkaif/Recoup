# Recoup

AI-orchestrated revenue recovery engine — detects, diagnoses, and recovers revenue at risk across payment failures, checkout abandonment, subscription mandates, and receivables.

## Monorepo Structure

- `frontend/` - Next.js 14, TypeScript, Tailwind CSS, App Router
- `backend/` - FastAPI, Python, Uvicorn
- `shared/` - JSON schemas shared between frontend and backend
